Política de Privacidad

En Agencia MarquetingIA, la privacidad de nuestros usuarios es nuestra prioridad. Esta política describe cómo manejamos la información.

1. Recopilación de Datos

Solo recopilamos información necesaria para la autenticación de usuarios a través de la API de TikTok y para mejorar la experiencia del usuario con nuestras herramientas de IA.

2. Uso de la Información

Los datos se utilizan exclusivamente para optimizar las campañas de marketing y la generación de contenido automatizado. No vendemos datos a terceros.

3. Seguridad

Implementamos medidas de seguridad técnicas para proteger sus datos contra accesos no autorizados.
